## User

| Field           | Type      | Constraints                    |
| --------------- | --------- | ------------------------------ |
| user_id         | PK        | autogenerated, unique          |
| username        | string    | required, min 5, max 50        |
| email           | string    | required, regex validated      |
| phone           | number    | optional                       |
| DOB             | date      | required, validated            |
| created_at      | timestamp | auto-generated                 |
| hashed_password | string    | bcrypt                         |
| last_log_in     | datetime  |                                |
| active_status   | enum      | active/inactive/banned/deleted |

## Post

| Field          | Type      | Constraints                           |
| -------------- | --------- | ------------------------------------- |
| post_id        | PK        | autogenerated                         |
| user_id        | FK        | references User                       |
| title          | string    | required, min 10, max 100             |
| caption        | string    | optional                              |
| media_type     | enum      | none/text/video/image                 |
| media_link     | string    | required if media_type is video/image |
| posted_at      | timestamp |                                       |
| deleted_status | bool      |                                       |

## Comment

| Field         | Type      | Constraints           |
| ------------- | --------- | --------------------- |
| comment_id    | PK        | autogenerated, unique |
| post_id       | FK        | references Post       |
| cmt_user_id   | FK        | references User       |
| description   | string    | min 3, max 150        |
| cmt_at        | timestamp |                       |
| delete_status | bool      |                       |

## Routes

**User**

| Method | Route          | Description             |
| ------ | -------------- | ----------------------- |
| POST   | /auth/login    | log in                  |
| POST   | /auth/register | register                |
| DELETE | /users/:id     | delete own account      |
| PATCH  | /users/:id/ban | admin-only, ban account |

**Post**

| Method | Route      | Description     |
| ------ | ---------- | --------------- |
| GET    | /posts     | get feed        |
| GET    | /posts/:id | get single post |
| POST   | /posts     | create post     |
| DELETE | /posts/:id | delete post     |

**Comment**

| Method | Route                   | Description                |
| ------ | ----------------------- | -------------------------- |
| GET    | /posts/:postId/comments | get all comments on a post |
| POST   | /posts/:postId/comments | add comment                |
| DELETE | /comment/:id            | delete comment             |
